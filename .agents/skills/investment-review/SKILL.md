# Investment Review

Paths below are relative to the repository root.

1. Read the original dated thesis and decision notes. Follow the root AGENTS.md research rules and mark missing contemporaneous evidence.
2. Reconstruct expectations using information available at the decision date. Label retrospective reconstruction separately.
3. Compare subsequent evidence against each material assumption. Evaluate process quality independently of price performance.
4. Complete templates/decision-review.md with supported findings, uncertainty, and changes to future behavior.
5. If saving is requested, store the review in learnings/reviews/ and capture reusable lessons using templates/learning.md. Update the learning index with links.

Complete when each lesson states a trigger, a concrete behavior, supporting evidence, and a future check.
