# Research

Start with [watchlist.md](watchlist.md). Create company folders as `companies/<exchange>-<ticker>/` using the [stock template](../templates/stock-analysis.md).

Keep the current thesis in `analysis.md`; save updates as `YYYY-MM-DD-results.md` or `YYYY-MM-DD-update.md`. Cite sources in the notes themselves. Optional supporting files belong beside the analysis, with their source and reporting period documented.
