# Learnings

Keep reusable concepts in `concepts/<topic>.md` and dated decision reviews in `reviews/YYYY-MM-DD-<exchange>-<ticker>.md`. Create those folders when saving the first note.

Use [the learning template](../templates/learning.md) for a concept or process lesson and [the decision template](../templates/decision-review.md) for a review. Link back to the original evidence. A single successful outcome is an observation; record what further evidence would support a general rule.
